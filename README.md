Solara Bay — an original open-world crime game in a sunlit coastal city, built from scratch in Three.js for the make.fun gta6-01 bounty. Explore the plaza, harbour, beachfront and downtown on foot or by car: steal cars, outrun the Bay PD through a 5-star wanted system, fight with fists and a pistol, and play six story missions with Tomas and Sal — from meeting at the fountain to a final beach getaway. 45 pedestrians with daily routines, 26 cars in traffic, a circular minimap, radio stations, and a localStorage save. Everything — city, characters, vehicles, story, art and sound — is original, procedural and offline: no network requests after load, no Rockstar assets.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `game/` with any static server (`python3 -m http.server` from inside `game/`) and open `index.html`. Desktop Chrome, keyboard + mouse: WASD move, mouse look, Shift run, E enter a car / talk, F punch, click shoot, R reload, Q radio, M mute, Esc pause.
